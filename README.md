Avatiah gives you a Photoshop-centered setup for designing an avatar. Instead of moving into another tool, you stay inside Adobe Photoshop and work the artwork there.

The intent is straightforward: one dedicated avatar project, edited with the image tools you already know, so design stays inside a single familiar environment.
